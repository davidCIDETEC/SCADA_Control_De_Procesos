Los usuarios en la base de datos deben ser usr @ % ('paul'@'%') para permitir la conexion desde el contenedor
Para las conexiones locales son usr @ 'localhost'

Se debe cambiar el tipo de acceso desde la base de datos:
sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf 
Buscar la linea bind-address y modificar por:
bind-address = 0.0.0.0

COMANDO PARA MONTAR IMAGEN DOCKER
docker build -t contenedor-v2 .

COMANDO PARA CORRER APLICACION DENTRO DE IMAGEN
docker run --rm -it -v /home/paul-1/pruebas:/app contenedor-v2 python3 conexion-mysql.py
